# Write a changelog entry

Add the entry under `## [Unreleased]` in one of these sections: Added, Changed, Deprecated,
Removed, Fixed, Security. One line per change, written for users, not for developers.
Reference the issue number at the end, for example `(#7)`. Do not edit released sections.
Group several small fixes into one line only when they share a cause.
When in doubt, prefer Fixed over Changed for bug fixes.
